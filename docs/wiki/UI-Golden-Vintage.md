# Golden Vintage UI Design

## Aesthetics & Token Rules
- **Color Palette (Golden Default)**:
  - Background: `#1A1810` / `#232018`
  - Surface: `#332E22` / `#3D372A` / `#453D30`
  - Highlights: `#F0D060` (border highlight), `#D4C89A` (text primary), `#9C9371` (text secondary)
  - Borders: `#100E08` (border dark), `#75663D` (bevel light), `#5A5040` (border muted)
- **Zero Antialiasing (No AA)**: Crisp pixelated font rendering and icons.
- **Physical Depth**: 2px raised and sunken Win95 bevels with zero blur or animations.
