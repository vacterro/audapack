# CLI & Silent Packaging

## Command Line Reference
- `pythonw AUDAPACK.pyw` — Launch desktop GUI.
- `pythonw AUDAPACK.pyw --silent` — Pack all enabled projects silently to configured output directory.
- `python AUDAPACK.pyw --install-context-menu` — Install Windows Explorer right-click integration.
- `python AUDAPACK.pyw --remove-context-menu` — Remove Windows Explorer integration.
- `python AUDAPACK.pyw --status` — Output audit room status to stdout.
- `python AUDAPACK.pyw --pack-project <id>` — Pack a single registered project.
