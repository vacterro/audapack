[P0] [CORE-001] audapack/packing.py::pack_single backup establishment / failed-pack rollback
EVIDENCE:
- `pack_single()` lines 565-575 moves an existing canonical archive to a backup before replacement, but an `OSError` from `output_path.replace(backup_path)` is swallowed by setting `backup_path = None`.
- Execution then continues into `create_zip()` and post-commit verification at lines 577-588.

DEFECT:

- Apply bounded Windows sharing-violation retry if appropriate, but never continue without confirmed rollback authority.

- Preserve the current same-target cross-process lock.
VERIFY:

- Existing concurrent same-target and partial-pack preservation tests remain green.
